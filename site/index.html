paper_tools
Local-first academic writing

WRITING, WITH EVIDENCE

研究メモから、
検証できる論文原稿へ。

入力した事実だけを使い、不足情報を明示しながら、構成、本文、Typst、PDFまでを一つのローカル画面で整えます。

起動済みのアプリを開く 起動方法を見る

WINDOWS QUICK START

ダブルクリックで起動

  1. このフォルダーにある START_PAPER_TOOLS.cmd をダブルクリックします。
  2. 初回だけ専用環境と必要なライブラリを自動で準備します。
  3. 準備が完了すると、ブラウザで論文作成画面が自動的に開きます。

起動中の黒い画面はサーバー本体です。閉じると安全にローカルアプリを停止できます。

WHAT STAYS LOCAL

論文作成に必要なものを、手元に。

アカウントや外部APIがなくても、主要な作業を始められます。

01

日本語・英語

8種類の論文構成と、言語ごとの学術文体に対応します。

02

事実を捏造しない

不足する数値、引用、図表をプレースホルダーと助言で示します。

03

Typst・PDF

編集可能な原稿を生成し、Typst導入時はPDFまで確認できます。

04

ローカル保存

プロジェクト、履歴、資料は端末上のSQLiteとフォルダーへ保存します。

GITHUB PAGES READY

公開ページと論文本体を分けています。

このページは静的HTMLなので、将来そのまま案内ページとして公開できます。

GitHub Pages側

製品紹介、起動手順、リリース版のダウンロード案内を担当します。

  • 静的HTMLのみ
  • 研究データを扱わない
  • APIキーを保存しない

ローカルアプリ側

論文編集、SQLite、Typst、Ollama、ファイル保存を端末内で担当します。

  • FastAPIの実画面
  • 原稿と履歴を保存
  • PDF・ZIPを生成

ブラウザの安全機能上、通常のHTMLだけでPythonを起動することはできません。そのため、Windowsでは起動用CMD、GitHub Pagesでは安全な案内ページという役割分担にしています。
