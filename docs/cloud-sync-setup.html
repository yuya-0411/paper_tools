端末間同期の初期設定

利用者の端末にPythonやNode.jsは不要です。管理者が最初に一度だけ設定します。

原稿を外部へ保存する設定です

未発表原稿や個人情報を扱う前に、所属組織がSupabaseの利用を許可しているか確認してください。

1．Supabaseを用意する

専用プロジェクトを作り、DashboardのSQL Editorで supabase/schema.sql を実行します。本人だけを許可するRLSと非公開Storageが作成されます。

2．招待制のメールOTPにする

Email認証を有効にし、新規サインアップと匿名ログインを無効にします。利用者は管理者が個別招待します。Magic Linkメールには {{ .Token }} を入れ、GitHub Pagesの正確なURLだけを許可します。

3．公開用の2項目だけを設定する

scripts/cloud-config.jsへProject URLとPublishable keyを記入し、enabledをtrueにします。Secret key、service_role key、データベースパスワードは記入しません。

4．GitHub Pagesを公開する

PagesのSourceをGitHub Actionsにします。公開前テストが、秘密鍵、RLSスキーマ、SDKハッシュ、ブラウザー起動を検査し、失敗した場合は公開を止めます。

5．既存原稿を1件ずつ移す

file://版で各プロジェクトのZIPを作り、GitHub Pages版へ読み込みます。その後ログインし、「端末間同期」から1件ずつ「クラウドへコピー」を実行します。別端末で原稿と添付を確認するまで元データを削除しません。

普段の編集

編集は先に端末へ保存されます。別端末へ反映するときだけ同期ボタンを押します。ログアウトしても端末内コピーは残ります。
