# English engineering paper sample

This original sample demonstrates the `engineering-two-column` template with a fictional thermal-actuator controller. It does not reproduce a third-party paper or an official venue template. Every experimental value is synthetic demonstration data and must not be cited as a real result.

The sample contains an abstract, method, results, a table, an original SVG figure, a Hayagriva reference file, split Typst sections, and CSV data. The sole external reference is the official Typst documentation and is cited only for the document tool. The engineering claims rely only on explicitly labelled synthetic data.

```bash
typst compile main.typ output/paper.pdf
```
